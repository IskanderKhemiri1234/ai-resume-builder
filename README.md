# 🚀 ResuMaker.AI | أداة إنشاء السيرة الذاتية بالذكاء الاصطناعي

منصة برمجية متكاملة (SaaS) لبناء سير ذاتية احترافية ومتوافقة مع أنظمة تتبع المتقدمين (ATS) باستخدام أحدث نماذج الذكاء الاصطناعي.

🔗 **رابط المعاينة المباشر:** [ResuMaker.AI](https://ai-resume-builder-46mc.vercel.app/)

---

## ✨ المميزات الرئيسية

- 🤖 **توليد ذكي ومخصص:** إنشاء سيرة ذاتية بناءً على المسمى الوظيفي، الخبرات، والمهارات.
- 🎯 **توافق مع نظام ATS:** نصوص ونقاط منظمة ومصممة لتجاوز أنظمة الفلترة الآلية في الشركات.
- 🌐 **دعم لغات متعددة:** توليد السيرة الذاتية باللغات العربية، الإنجليزية، والفرنسية.
- 🖨️ **تصدير مباشر إلى PDF:** تنسيقات طباعة مخصصة لتصدير السيرة الذاتية بخلفية بيضاء خالية من أزرار الموقع.
- 📋 **نسخ سريع:** زر مخصص لنسخ نص السيرة الذاتية مباشرة بنقرة واحدة.
- 📱 **تصميم تجاوبي:** واجهة حديثة مصممة بـ Tailwind CSS تعمل بكفاءة على مختلف الشاشات والهواتف.

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** HTML5, Tailwind CSS, JavaScript (ES6+)
- **الواجهة الخلفية (Backend):** Node.js / Vercel Serverless Functions (`api/generate.js`)
- **نماذج الذكاء الاصطناعي:** DeepSeek R1 & Gemini 2.0 Flash عبر OpenRouter API
- **الاستضافة والنشر:** Vercel
