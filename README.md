# 🚀 ResuMaker.AI | مولد السير الذاتية الاحترافي بالذكاء الاصطناعي

منصة برمجية متكاملة (SaaS) لبناء سير ذاتية احترافية ومتوافقة تماماً مع أنظمة تتبع المتقدمين (ATS) باستخدام الذكاء الاصطناعي خلال ثوانٍ معدودة.

🔗 **الرابط المباشر للمشروع:** [ResuMaker.AI](https://ai-resume-builder-46mc.vercel.app/)

---

## ✨ المميزات الرئيسية

- 🤖 **توليد ذكي ومستهدف:** صياغة سير ذاتية مخصصة بناءً على المسمى الوظيفي، الخبرات، والمهارات.
- 🎯 **توافق كامل مع ATS:** مخرجات نقيّة ومصممة لتجاوز أنظمة الفلترة الآلية في الشركات العالمية.
- 🌐 **دعم متعدد اللغات:** إمكانية التوليد باللغة العربية، الإنجليزية، والفرنسية.
- 🎨 **تنسيقات طباعة متقدمة (CSS Print):** تصدير مخصص إلى PDF بنقرة زر واحدة بخلفية بيضاء ونصوص واضحة.
- 📋 **نسخ سريع:** إمكانية نسخ النص المولد فوراً بأسلوب محاذي للتنسيق.
- 📱 **واجهة تجاوبية بالكامل:** تصميم حديث بـ Tailwind CSS يدعم جميع أجهزة المحمول والشاشات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend:** Node.js / Vercel Serverless Functions (`api/generate.js`)
- **AI Models:** DeepSeek R1 / Gemini 2.0 Flash عبر OpenRouter API
- **Deployment:** Vercel
